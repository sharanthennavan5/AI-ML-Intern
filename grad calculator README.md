# Student Grade Calculator

This is a simple Python project that calculates the grade of a student based on their marks.

## About the Project

The program asks for the number of students, their names, and their marks. Based on the marks entered, it automatically assigns a grade.

This project was created as part of my AI & ML internship to practice Python conditional statements and basic data handling.

## Grade System

| Marks | Grade |
|------|------|
| 90 - 100 | A+ |
| 80 - 89 | A |
| 70 - 79 | B |
| 60 - 69 | C |
| 50 - 59 | D |
| 0 - 49 | F |

Marks below 0 or above 100 are considered invalid.

## Tools Used

- Python
- Google Colab

## How to Run

1. Open the Python file in Google Colab.
2. Run the program.
3. Enter the number of students.
4. Enter each student's name and marks.
5. The program will display the marks and corresponding grade.

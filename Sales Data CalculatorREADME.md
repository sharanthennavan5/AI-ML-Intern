# Sales Data Calculator

This project is a simple Python-based sales data analysis task completed as part of my AI & ML internship.

## Project Overview

The program analyzes a manually created list of sales values and calculates some basic statistics from the data.

## What It Calculates

- Total sales
- Average sales
- Highest sale
- Lowest sale

## Tools Used

- Python
- Jupyter Notebook / Google Colab

## How It Works

A list of sales values is created in Python. The program then uses basic built-in functions such as `sum()`, `max()`, and `min()` to calculate the required results. The average is calculated using the total sales divided by the number of sales values.

## Output

The program displays the sales data along with the total, average, highest, and lowest sales values.

## Learning Outcome

This task helped me understand the basics of numerical data analysis using Python and how simple Python functions can be used to extract useful information from sales data.

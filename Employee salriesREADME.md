# Employee Salary Analysis

## About the Project

This project is a simple Python program created to analyze employee salary data. It calculates the total salary, average salary, highest salary, and lowest salary from the given employee records.

## What I Used

- Python
- Google Colab
- Pandas
- Matplotlib

## What This Project Does

The program stores employee names and salary details and performs basic calculations on the data.

It can:

- Calculate the total salary
- Find the average salary
- Find the highest salary
- Find the lowest salary
- Identify the highest and lowest paid employees
- Compare the original salary data with the calculated data
- Display the data using Pandas
- Create a simple salary chart using Matplotlib

## Dataset

The employee data used in this project was manually created for analysis and practice.

## Output

The program displays the employee salary details along with the calculated salary statistics. It also generates a bar chart to make the salary comparison easier to understand.

## What I Learned

Through this project, I practiced using Python lists, built-in functions like `sum()`, `max()`, and `min()`, and learned how Pandas and Matplotlib can be used for basic data analysis and visualization.

## Conclusion

This project helped me understand the basics of working with numerical data in Python and gave me practical experience with simple data analysis.
